활동지 사용 안내

  1. 이전·다음 버튼이나 키보드 ← →로 한 화면씩 이동합니다. 글을 쓰는 동안에는 방향키로 페이지가 바뀌지 않습니다.
  2. 목차의 다리에서 각 BRIDGE 단계를 누르면 그 단계의 설명을 볼 수 있습니다. 화면 이동은 이전·다음 버튼과 아래쪽 쪽 번호로 합니다.
  3. 입력은 자동 저장됩니다. 수업이 끝나면 저장으로 JSON 파일을 보관하고, 불러오기로 이어서 작성하세요.
  4. 한 활동이 여러 화면으로 나뉜 경우 화면 아래의 쪽 번호 단추로 채운 화면(초록색)과 빈 화면을 확인할 수 있습니다. 모두 채운 뒤 마지막 화면에서 활동 완료를 누르세요. 완료한 활동은 잠기며, 고치려면 ‘완료 취소’를 누릅니다.
  5. 알지오3D 모델은 도구에서 .algeo3d로 따로 저장하세요. 학습 기록 JSON에는 답변·스케치·첨부 이미지가 담깁니다.

작은 화면은 세로로 배치됩니다. 외부 도구가 비어 보이면 새 창으로 열거나 HTML 파일을 Edge·Chrome으로 열어 주세요.

알지오3D 도형 저장

편집용 모델: 도구 메뉴의 ‘다른 이름으로 저장 → 내 PC 저장’으로 .algeo3d 파일을 보관하세요. ‘열기 → 내 PC에서 열기’로 다시 열 수 있습니다.

색칠·장식용: STL로 내보낸 뒤 그림판3D에서 불러오세요.

페이지 이동 중에는 열어 둔 도구를 유지합니다. 새로고침·종료 전에는 모델을 따로 저장하세요. 상단의 학습 기록 저장에는 알지오매스 모델이 포함되지 않습니다.
